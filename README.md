# poe2-watcher — Divine News Radar

Бесплатный сторож новостей Path of Exile 2: каждые ~10 минут GitHub Actions проверяет источники
и шлёт пуши в Telegram. Без Claude и без токенов ИИ — только Python (`requests` + `feedparser`).

## Что проверяет

| Источник | Как | Срочно 🔥 | В дайджест 📌 |
|---|---|---|---|
| GGG — форумы PoE 2 | «Early Access Patch Notes» (2212), «Early Access Announcements» (2211), «Path of Exile 2 Press Releases» | **любая новая тема** (`all_urgent: true`) | — (темы старше 36 ч никуда не идут, `ggg.digest_max_age_hours`) |
| GGG — RSS новостей | `pathofexile.com/news/rss` (это форум «Announcements» PoE 1, туда же идут общие новости). Игру определяем по заголовку, иначе по странице темы | любой пост про PoE 2 (`news_poe2_all_urgent`) | — ; посты **только про PoE 1** (Covens of Umbra и т. п.) не шлются вообще |
| GGG — дев-трекер | [gggtracker.com](https://gggtracker.com) `activity.json` — посты сотрудников GGG с форума; берём только форумы PoE 2 (`ggg.dev_tracker`), без баг-репортов и торговли | новая тема GGG 🔥 (часто раньше, чем страница форума); 💬 ответ сотрудника GGG в теме фидбэка/обсуждений/билдов PoE 2 | — |
| GGG — сайт pathofexile2.com | `internal-api/content.json` — разделы сайта (страница анонса, классы, лига, блоки) | 🆕 новый раздел или блок на сайте (тизер, раскрытие) | — |
| poe2db.tw (датамайн) | раз в 30 мин (`poe2db.every_minutes`): главная — версии данных игры и страницы новой лиги (`<Лига>_uniques/_gems/_items`), эти страницы, `Ascendancy_class` | 🧬 новая версия данных; новые уники / геммы / предметы лиги (одним пушем со списком); новый класс или восхождение | при отказе сайта — строка в «сбоях» дайджеста |
| Reddit r/PathOfExile2 | RSS `/new` и `/top?t=day` (или API, если заданы `REDDIT_CLIENT_*`) | 📣 пост сотрудника GGG (автор `*_GGG`, `GGG-*`, `reddit.ggg_authors`) или с флером News / Information / Announcement — без порога апвоутов (флер виден только через API); пост в топе дня со словами exploit, dupe, ban, RMT, world first, level 100; с API — ещё ≥ 3000 апвоутов за 3 ч | топ дня |
| YouTube | RSS всех каналов из `config.json` (бесплатно), просмотры — `videos.list`, поиск `search.list` раз в 30 мин (en и ru по очереди) | ролик по PoE 2 в 5× быстрее нормы канала; канал ≥ 200K подписчиков не из списка впервые про PoE 2 (PoE 2 — в названии ролика, описание не в счёт; «впервые» проверяется по RSS канала: если среди последних 15 роликов уже есть PoE / Path of Exile, ролик идёт в дайджест); **любой новый ролик официального канала GGG**, кроме подписанных как PoE 1 | новые ролики каналов из списка — только про PoE 2 (без 3.xx/PoE 1; без слова PoE 2 — если канал в основном про PoE 2); ролики каналов не из списка ≥ 20K — без PoE 1 и только с названием на английском или русском (это же правило и для 📺) |
| Twitch | Helix: топ-100 трансляций категории, клипы за 3 ч, фолловеры | канал не из базы впервые в PoE 2 с ≥ 3000 зрителей или ≥ 50K фолловеров и ≥ 300 зрителей (зашёл с меньшим — ждём до 12 ч, пока наберёт); любой из «звёзд»; клип ≥ 50K просмотров за 3 ч | новые стримеры ≥ 300 зрителей, клипы ≥ 5K |
| 🔥 Клип (`clips.py`) | Twitch: клипы категории PoE 2 за 24 ч (до 300), снапшоты просмотров каждый прогон; watchlist — топ-50 стримеров PoE 2 по пиковым зрителям за 7 дней (пересчёт раз в сутки). YouTube: ролику < 24 ч (не PoE 1) и ≥ 2000 просмотров и скорость ≥ 3× средней канала, или ≥ 20K за первые 6 ч. Один пуш на клип; «🚀 Разгоняется» — если скорость выросла втрое; ≥ 3 клипа за час про одно (стример или общее слово в названиях) — один пуш «🔥 Событие» | — |
| vaal.tools (фан-сайт, не GGG) | раз в 30 мин (`vaal_tools.every_minutes`) одна страница `vaal.tools/release-1-0/`: всё раскрытое к 1.0 по категориям (Gems, Items, Item Mods, Crafting, Passive Tree, Ascendancy Nodes, Conquerors of Wraeclast, Mechanics Changes, Atlas Tree, Sources) и подстраницы `/release-1-0/<тема>/` | 🧩 новые записи — один пуш на категорию с именами; новая подстраница — отдельный пуш | — |

Дайджест уходит одним сообщением в 21:00 по Риму (летнее/зимнее время учитывается само).
Внизу дайджеста — какие источники сегодня сбоили. Reddit там не показывается, пока нет ключей `REDDIT_CLIENT_*` (без них он отказывает всегда).

**Норма канала YouTube** — медиана просмотров первых 6 ч по последним 10 роликам. Пока замеров меньше трёх,
берётся заготовка: 35 % медианы просмотров роликов старше 3 дней (`youtube_norm_bootstrap_fraction`).

**Первый запуск** (и любой новый источник) молча запоминает всё, что уже есть, — пушей о старом не будет.
У источников без дат (poe2db, сайт PoE 2) так же и при `--no-seed`: иначе «всё как новое» — сотни пушей о том, что лежит на сайте давно.

**Не проверяется:** X/Twitter GGG — бесплатного API нет. Мелкие YouTube-каналы с пересказами не добавляем.

**Клипы.** Пуш: `🔥 Клип · Twitch · стример · 4 200 просм. за 1,5 ч (+900/ч) · «название» · 0:28 · ссылка`
(+900/ч — текущая скорость по снапшоту 15 мин…3 ч назад). Шортсы — `YouTube Shorts`. Средняя канала YouTube —
просмотров в час за первые сутки по последним 10 роликам (свои замеры; пока их < 3 — 50 % просмотров роликов
старше суток / 24, `youtube_bootstrap_first_day_share`). Пороги — `config.json` → `clips`.
Оценка «что пришло бы за последние сутки»: `python clips.py --sim24` (можно `--set twitch_views=2000`).

## Как поменять пороги
`config.json` → раздел `thresholds` (имена говорят сами за себя), правка прямо на GitHub → Commit.
Следующий прогон возьмёт новые значения. Ключевые слова — раздел `keywords`.

## Как добавить источник
- **YouTube-канал:** `config.json` → `youtube.channels` → `{"name": "Имя", "id": "UC…"}`.
- **Twitch-стример PoE (чтобы не считался «новым»):** `twitch.known_streamers`, ник маленькими буквами.
- **Звезда (пуш, как только зайдёт в PoE 2):** `twitch.stars`.
- **Форум GGG:** `ggg.forums` → `{"name": "…", "url": "https://www.pathofexile.com/forum/view-forum/<id>", "all_urgent": true}`
  (`all_urgent: false` — срочно только темы со словами из `keywords.ggg_urgent`).
- **Форум PoE 2 в дев-трекер:** id форума в `ggg.dev_tracker.poe2_forum_ids` (и в `reply_forum_ids`, если нужны ответы GGG в чужих темах).
- **Лига PoE 1, которую не надо слать:** `keywords.poe1_only`.
- Новый тип источника — функция `check_<имя>(run)` в `watcher.py` и строка в `main()`.

## Как запущен
Вахтами: одна задача Actions гоняет `watcher.py` каждые 10 минут ~5 ч 45 мин, перед каждым прогоном берёт
свежий `main`, после каждого сохраняет state, в конце сама ставит следующую вахту (`gh workflow run`).
Cron раз в час — только запасной перезапуск (в очереди одновременно не больше одной вахты, лишние GitHub
отменяет — серые «cancelled» в Actions это нормально). Правки `config.json` подхватываются со следующего прогона.

## Как остановить
GitHub → репозиторий → **Actions** → workflow **watch** → «⋯» → **Disable workflow** (и Cancel у идущей вахты).
Включить — там же, Enable, затем **Run workflow**.
Разово запустить: Actions → watch → **Run workflow** (галочка «Отправить дайджест сейчас» — дайджест немедленно).

## Ключи (GitHub → Settings → Secrets and variables → Actions)
`TG_TOKEN`, `TG_CHAT_ID`, `YT_API_KEY`, `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET`;
необязательно `REDDIT_CLIENT_ID`, `REDDIT_CLIENT_SECRET`. Ключи не пишутся ни в код, ни в репозиторий.
Нет ключа — источник просто пропускается (GGG и RSS YouTube работают без ключей).

## Состояние
`state.json` (что уже видели, история стримеров, нормы каналов, квота YouTube) хранится в ветке **`state`**:
после каждого прогона бот перезаписывает её одним коммитом, чтобы `main` не обрастал тысячами коммитов.
Сбросить память сторожа — удалить ветку `state` (следующий прогон заново молча всё запомнит).

## Локально
```
pip install -r requirements.txt
python watcher.py --dry-run                       # ничего не шлёт, state не пишет
python watcher.py --dry-run --no-seed --digest-now  # пример: всё найденное как новое + дайджест
python watcher.py --test-message                  # тестовое сообщение в Telegram (можно свой текст: --test-message "…")
python tg_setup.py                                # найти chat_id после /start боту
```
Ключи локально — в `.env` (в `.gitignore`).

## Ограничения
- Cron GitHub для этого репозитория срабатывал раз в несколько часов — поэтому вахты (см. «Как запущен»).
- Reddit режет анонимный доступ (429/403). При отказе прогон Reddit пропускается и пишется в «сбоях» дайджеста.
  Надёжно — Reddit-приложение типа *script* и ключи `REDDIT_CLIENT_*`.
- Квота YouTube 10 000 в день; сторож сам держит расход ≤ 6 000 (`youtube_daily_quota_cap`).
- Публичный репозиторий не получает расписание навсегда: если 60 дней нет активности, GitHub выключает cron
  (придёт письмо) — включить кнопкой Enable workflow.
- VK Видео Live и Kick не проверяются.
